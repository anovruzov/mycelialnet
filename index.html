ConstraintRemote-only analysisMycelic design
LatencyNew decisions wait for transport, ingestion, analysis, and a return instruction.Eligible local decisions avoid that round trip. Collective findings still pay for evidence exchange and verification.
DisconnectionA disconnected endpoint cannot receive a new remote decision.Local checks can continue within installed policy. Network-wide discovery cannot see unreachable peers.
Private evidenceCentral analysis cannot directly inspect raw evidence it is forbidden to receive.Agents inspect evidence locally and exchange scoped findings with provenance. Shared findings still need access control.
Weak signals over timeCan correlate signals that were collected and retained. Missing source context cannot be reconstructed from nothing.Local temporal memory preserves context for follow-up questions. Discovery seeks supporting and contradictory evidence across sources.
Load and failureA shared decision service can queue or fail; replication and sharding can mitigate both.Local decisions distribute work and limit reliance on one service. Peer traffic, device limits, compromised nodes, and verification add costs.
ContainmentCan enforce through connected endpoint, identity, and network controls.Proposed local enforcement uses those same authorized controls. An LLM alert alone cannot isolate a workload or revoke a token.

Hybrid systems with local enforcement can share these advantages. References: NIST fog computing and NIST policy enforcement.
